# 📄 職務経歴書 作成ツール

職歴や担当した業務、資格・スキルなどを画面に沿って入力し、職務経歴書の形にまとめることができるWebアプリです。

「職務経歴書を作りたいけれど、何を書けばいいのか分からない」
「自分がしてきた仕事を、どのように表現すればいいのか分からない」

そんな人でも、自分の経験を一つずつ振り返りながら、できるだけ迷わず作成できるようにしました。

PCだけでなくスマートフォンからも入力・確認でき、完成した職務経歴書は印刷・PDF保存することができます。

## 💡 制作した理由

職務経歴書を作成する際、「何を書けばいいのか分からない」「自分が担当していた仕事をどのように表現すればいいのか分からない」と迷うことがあります。

特に職種や業務内容については、自分の経験を振り返りながら一から文章を考えること自体が負担になる場合もあります。

そこで、職種や主な業務内容などを選択肢から選びながら入力でき、必要に応じて「その他」や補足欄を使って、自分の経験も追加できる形にしました。

また、現在働いていて転職を考えている人だけではなく、これから初めて就職活動をする人にも使ってもらえるものにしたいと思い、正社員としての職歴だけに限定せず、アルバイトなどの経験についても入力できるようにしています。

営業や事務、ITだけでなく、接客・飲食、製造・物流、医療・福祉、教育・保育など、さまざまな経験を選択しながら整理できるようにしました。

例えば、アルバイトで「レジ対応」「品出し」「在庫管理」「発注」などを経験していた場合も、選択肢を見ながら「そういえば、この仕事もしていた」と自分の経験を振り返ることができます。

職歴の多い・少ないにかかわらず、自分の経験を一つずつ振り返りながら入力することで、職務経歴書の作成に慣れていない人でも、できるだけ迷わず最後まで作成できるようにしました。


## 👥 こんな人に使ってほしい

例えば、次のような人に使ってもらうことを考えて作成しました。

- 転職活動のために、これまでの職歴を整理したい人
- 初めて職務経歴書を作成する人
- これから就職活動を始める人
- アルバイトなども含めて、自分が経験してきた仕事を整理したい人
- 自分が担当してきた業務を、どのように書けばよいのか迷っている人


## ✨ 主な機能

### 🏢 職歴の登録

会社ごとに職歴を追加し、それぞれの勤務情報を入力できます。

- 会社名
- 入社年月
- 退職年月
- 在職中の設定
- 雇用形態
- 役職・リーダー経験

職歴は複数追加できるため、これまで勤務した会社やアルバイトなどの経験を分けて整理できます。


### ⚙️ 担当職種・業務内容

1つの職歴の中に、担当した職種・業務内容を複数登録できます。

職種カテゴリ、職種詳細、主な業務内容、業務頻度などを選択しながら入力できます。

営業・販売、事務・企画・管理、接客・サービス・飲食、IT・Web、クリエイティブ、製造・物流・技術、医療・福祉、教育・保育など、さまざまな経験を整理できるようにしています。

職種によっては、その仕事に合わせた具体的な業務内容も選択できるようにしました。

選択肢に自分の経験した職種や業務がない場合は、「その他」を利用して自分で内容を入力することもできます。

また、具体的な実績や担当内容などは補足欄へ自由に入力できます。


### 🏆 成果・実績

仕事の中で得た成果や実績について、数字や具体的な内容を自由に入力できます。

選択式だけでは表現できない、自分自身の経験や実績を記録するための欄として用意しました。


### 🎓 保有資格・スキル

保有している資格を複数登録できます。

- 取得年月
- 資格カテゴリ
- 資格名
- スコア・級・補足

主な資格については選択肢から選ぶことができ、リストにない資格については直接入力することもできます。

登録した資格は取得年月順に整理して表示されます。

また、資格とは別に、Excel、CAD、プログラム言語などの使用可能なツールや特記事項についても自由に入力できます。


### 💡 身についたこと・アピール点

これまでの経験を振り返りながら、身についたことや今後の仕事で活かしたいことを整理して入力できます。

- これまでの業務で身についたこと
- 次に活かしたい点・自己PR

職歴や資格だけでは伝えにくい、自分自身の経験や強み、今後どのように活かしていきたいかを整理するための欄です。


### 💾 途中保存

入力途中の内容をブラウザに保存できます。

一度ですべて入力する必要はなく、途中で保存してから続きを入力できます。


### 📄 完成プレビュー

入力した内容を、実際の職務経歴書に近い形で確認できます。

氏名や会社名、職種・業務内容などの必要な項目が未入力の場合は確認メッセージを表示し、入力漏れに気づけるようにしています。

入力内容を確認して、修正したい場合は再び入力画面へ戻ることができます。


### 🖨️ 印刷・PDF保存

完成プレビューから印刷画面を開き、職務経歴書を印刷したりPDFとして保存したりできます。


### 🗑️ 全内容リセット

入力した内容をまとめて初期状態に戻すことができます。

誤操作を防ぐため、リセットする前に確認画面を表示するようにしています。


## 📱 スマートフォン対応

PCだけでなく、スマートフォンからも入力・編集・プレビューができるようにしました。

画面の幅に合わせて入力欄やボタンの配置が変わるため、スマートフォンでも操作できます。

スマートフォンから印刷画面を開き、PDFとして保存することもできます。


## 🔒 入力データについて

入力した内容はブラウザ内に保存する仕組みにしており、サーバーへ送信して保存する仕組みは使用していません。

「全内容をリセット」を実行すると、保存していた入力内容も削除されます。

## 🌱 今後の改善について

現在、さまざまな職歴や経験に対応できるよう、主な職種・業務内容・資格などを選択肢として用意しています。

世の中には本当にさまざまな仕事や資格があるため、すべてを最初から用意することは難しいと思っています。そのため、まずは主な職種や業務内容、資格を選択できるようにし、選択肢にないものについては「その他」や直接入力から自由に追加できるようにしました。

今回作って終わりではなく、実際に使ってもらう中で気づいたことや、「こんな機能があったら使いやすい」という意見があれば、それも参考にしながら少しずつ改善していきたいと思っています。
